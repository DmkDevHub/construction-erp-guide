# 건설안전 ERP 학습 교재

건설업을 처음 접하는 전사적 자원 관리(Enterprise Resource Planning, ERP) 개발자가 건설현장의 업무와 안전관리 기록을 이해하기 위한 교재입니다. 현장 조직과 작업을 먼저 익힌 뒤, 법령에서 요구하는 사항을 누가 언제 수행하는지, 어떤 ERP 기능과 증빙이 그 업무를 뒷받침하는지 추적합니다. 학습 범위는 건설업·안전관리 도메인과 ERP 업무 분석입니다.

## 학습 방법

1. 사진과 작업 그림을 먼저 보고 **어디서, 누가, 무엇을 하는지** 말해 봅니다. 본문에서 한글 명칭과 영문 명칭, 약어의 의미를 확인합니다.
2. 사례에 적용되는 **법적 의무, 공식 권고, 일반 현장 관행, 회사 기준**을 확인합니다. 법령 장에서는 시행일, 적용 조건, 의무 주체와 예외를 함께 읽습니다.
3. 흐름도와 양식을 보며 **담당자 → 수행 시점 → 입력 → 검토·승인 → 결과·증빙**을 따라갑니다. 작업 조건이 바뀌거나 점검에서 문제가 발견됐을 때 어디로 되돌아가는지도 확인합니다.
4. ERP 장에서 **법령 → 현장 업무 → 업무 절차 → ERP 기능 → 결과·증빙**을 역으로 추적합니다. 화면 캡션을 통해 실제 확인된 메뉴와 학습용 예시를 식별합니다.
5. 각 장의 확인 문제를 풀고 해설의 판단 근거를 확인합니다. 마지막에는 한 현장의 위험성평가, 작업 전 안전점검회의, 점검·시정조치 기록을 연결해 봅니다.

## 작성 상태와 바로가기

5개 장과 확인 문제·해설을 작성했습니다. 위 표에서 각 장을 열 수 있습니다. [ROADMAP.md](./ROADMAP.md)에 절별 목차·시각 자료 계획과 작성·검토 결과를 정리했습니다.

현업 자료는 저장소와 같은 상위 폴더의 로컬 `ref/`에서 확인합니다. 법령이나 회사 기준이 바뀌면 책의 확인일, 적용 근거, 관련 사례·그림·ERP 증빙이 함께 바뀌는지 점검합니다.
