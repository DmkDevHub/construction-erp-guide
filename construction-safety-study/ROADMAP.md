# 건설안전 ERP 학습 로드맵

[교재 안내](./README.md) · 작성 계획 기준일 2026-11-27 · **사용자 승인 대기**

## 목차 검토와 학습 설계

첨부 요청의 다섯 단계를 유지합니다. 01장은 현장에서 보는 작업과 사람을, 02장은 작업에서 발생하는 위험과 관리 수단을, 03장은 그 수단을 요구하는 법적 근거를 다룹니다. 04장에서 사람과 문서가 움직이는 순서를 익힌 뒤, 05장에서 같은 업무를 ERP 메뉴·권한·증빙으로 재구성합니다.

단계 간 연결을 확인할 수 있도록 지하 굴착과 철근콘크리트 골조 작업이 있는 가상 건축 현장을 공통 사례로 사용합니다. 굴착 장비와 보행자 동선, 개구부 주변 작업, 협력업체 동시 작업을 같은 현장의 기록으로 이어갑니다. 토목·플랜트의 차이와 공사 규모·조건별 법령 적용은 별도 사례에서 비교합니다. 실제 현장 사례는 공개된 공식 사례나 재사용 범위가 확인된 현업 자료를 참고해 출처를 붙입니다.

초급에서는 사진 판독과 용어 구분, 중급에서는 역할과 문서 흐름 재구성, 심화에서는 적용 조건 판단과 변경·누락된 증빙 추적을 연습합니다. 공정·공종 구분, 산업재해·중대재해·중대산업재해 구분, 서로 다른 법령의 안전 관련 계획서와 비용 구분, 허가·점검·시정조치의 연결을 명시해 단계 사이의 빈틈을 줄입니다.

## 02 건설안전 기초

**도달 목표** — 장면에서 위험을 발견하고 발생 가능한 재해와 예방 수단, 확인할 담당자를 설명합니다.

| --- | --- | --- |
| 02.1 | 건설안전의 목적. 유해·위험요인(Hazard), 위험성(Risk), 사고·건강장해의 관계 | 개구부 사례로 위험요인에서 노출과 피해로 이어지는 경로 그림 |

| 02.6 | 개인보호구(Personal Protective Equipment, PPE). 안전모·안전화·안전대·보안경·방진마스크·청력보호구의 선택과 착용 확인 | 보호구 실사진과 착용 확인 지점의 주석 그림. 잘못된 착용은 그림 안에 명시 |

## 03 건설안전 관련 법령

**도달 목표** — 공사 조건별로 적용 법령과 의무 주체를 찾아 실제 수행 업무 및 입증 자료에 연결합니다.

| 절 | 상세 학습 목차 | 제작·수집할 시각 자료 |
| --- | --- | --- |
| 03.1 | 법률·시행령·시행규칙·별도 규칙·고시의 관계. 법적 의무, 공식 권고, 일반 관행, 회사 기준을 읽는 법 | 법령 체계도와 조문 → 별표·서식 → 현장 적용 순서 그림 |
| 03.2 | 산업안전보건법. 목적, 사업주와 도급인·관계수급인·건설공사발주자의 책임, 안전·보건조치, 교육·위험성평가, 사고 대응 | 도급 관계별 의무 주체 지도와 현장에서 남기는 증빙 카드 |
| 03.3 | 산업안전보건법 시행령·시행규칙. 선임·교육·서류·보고와 규모·조건별 적용 기준 확인 | 공사 조건을 입력해 별표·서식을 찾아가는 적용 판단도 |
| 03.4 | 산업안전보건기준에 관한 규칙. 장소·설비·작업별 조치와 안전시설·장비·보호구의 관계 | 굴착·개구부·양중 사례의 조문과 예방 조치를 연결한 작업 그림 |
| 03.5 | 중대재해 처벌 등에 관한 법률(중대재해처벌법) 및 시행령. 적용 대상, 경영책임자등의 의무, 이행 점검과 현장 자료 | 본사 의무와 현장 이행 증빙이 연결되는 조직·증빙 지도 |
| 03.6 | 건설기술 진흥법 및 시행령·시행규칙 등 하위 규정. 안전관리계획, 안전점검, 건설사고, 발주·시공·검토·제출 역할 | 착공 전 계획부터 시공 중 점검·준공 기록까지 주체별 제출 흐름도 |
| 03.7 | 건설업 산업안전보건관리비 계상 및 사용기준. 적용 범위, 계상·사용·정산, 확인·보존 자료. 건설기술 진흥법상 안전관리비와의 차이 | 두 비용의 목적·근거·처리 경로 비교 그림과 증빙 예시 |
| 03.8 | 사업장 위험성평가에 관한 지침. 위험성평가의 절차, 참여·공유·기록, 시행일과 부칙 확인 | 위험성평가 단계도와 평가표에서 후속 조치까지 이어지는 사례 |
| 03.9 | 계획서와 대장의 적용 비교. 건설공사 안전관리계획, 유해·위험방지계획서, 안전보건대장의 목적·대상·역할 | 하나의 가상 현장에 필요한 문서를 판단하는 분기 그림과 단계별 제출 지도 |
| 03.10 | 위반 시 책임과 제재의 구분. 행정조치·과태료·형사책임 등의 근거와 적용 조건을 찾는 법 | 의무 불이행 사실 → 확인할 조문 → 대상과 조치로 연결되는 사례 그림 |
| 03.11 | 공사 조건별 적용 연습과 ERP 매핑. 공사금액·인원·공종·시점 등 사실 확인부터 담당자·입력·증빙까지 | 조건이 다른 두 현장의 판단 경로와 ‘법령 → 업무 → 절차 → ERP → 증빙’ 지도 |

**사례와 확인 문제** — 공사 규모와 작업 조건이 다른 두 현장에 적용할 의무를 찾아봅니다. 해설에는 판단에 쓴 조문·별표, 시행일, 필요한 추가 사실과 업무 증빙을 제시합니다.

## 04 안전관리 업무 프로세스

**도달 목표** — 실제 건설현장의 일과를 따라 업무 시작 조건에서 결과 확인까지 인계하고, 변경이나 미완료 상황을 처리할 수 있습니다.

| 절 | 상세 학습 목차 | 제작·수집할 시각 자료와 양식 예시 |
| --- | --- | --- |
| 04.1 | 안전보건 방침·목표·실행계획 수립. 자원 배정, 성과 점검과 개선 | 본사·현장 목표 연계도와 목표 추진계획서 및 실적 예시 |
| 04.2 | 현장 개설·공사 조건 변경·현장 종료. 조직·공종·일정 설정과 협력업체 선정·투입·평가 | 현장·협력업체 업무 흐름도와 투입 확인표·평가표 |
| 04.3 | 근로자 투입·변경·퇴장. 소속·작업·자격·교육·보호구 확인 | 신규 투입 절차 그림과 가명 근로자 투입·보호구 지급 기록 |

## 본문 작성 기준

- 각 절은 학습 목표와 기본 개념, 상세 설명과 그림, 구성요소와 역할, 현장 사례, 관련 근거, 절차, ERP 연결, 주요 용어, 핵심 요약, 확인 문제와 정답·해설, 출처 순서를 기본으로 합니다. 성격상 해당하지 않는 부분은 생략할 수 있으며 주요 절마다 해당 설명 바로 아래에 그림을 배치합니다.
- 업무마다 목적, 시작 조건과 시점, 수행자·협의자·검토자·승인자, 입력, 절차, 예외, 결과와 증빙을 기록합니다. 법정 서식, 기관 제공 예시, 회사 양식, 학습용 가상 양식은 캡션에서 식별할 수 있게 합니다.
- ERP 모듈은 목적·메뉴·주요 기능에서 시작해 역할과 조회 범위, 입력과 결과, 상태별 제어, 연계 대상, 남는 증빙을 다룹니다. 권한은 직책과 구분해 등록·검토·승인·조회 등 업무 행위로 설명합니다.
- 확인 문제는 용어 구분, 그림 읽기, 업무 선택, 적용 근거 확인, 증빙 추적을 단계 난이도에 맞춰 구성합니다. 해설에는 선택 이유와 현장 적용 결과를 함께 제시합니다.

2. 장별 폴더에 내용이 드러나는 파일명으로 저장합니다. 예를 들어 `assets/images/02_건설안전_기초/개구부-방호-비교.svg`를 쓸 수 있습니다. Markdown에서 상대경로와 대체 텍스트를 사용하고 각 그림에 제목·설명과 실제 사진/자체 제작 예시 표기를 붙입니다.
3. 사진은 작업 또는 설비를 알아볼 수 있는 해상도로, 자체 제작 그림은 한글 명칭과 화살표가 확대해도 읽히는 SVG를 기본으로 준비합니다. 복잡한 그림은 단계별로 나누고 비교 그림에는 ‘위험 사례’와 ‘개선 사례’를 문자로 표시합니다. 사진·작업 삽화·장비 단면도·화면 모형을 적극 활용하고, Mermaid 흐름도가 기본 미리보기에서 표시되지 않으면 SVG를 함께 준비합니다.
4. 제작 후 그림의 장비·동선·방호시설·보호구 표기가 본문과 맞는지 공식 근거로 대조합니다. 기준 판단에 필요한 현장 조건을 캡션에 밝히고, 위험 장면의 표시가 누락되거나 일부 조치가 안전을 보장하는 것처럼 보이는 그림은 수정합니다.
