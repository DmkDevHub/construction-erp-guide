# 건설업 ERP 하자관리 학습 교재

건설업에 처음 입문하는 전사적 자원 관리(Enterprise Resource Planning, ERP) 개발자를 위한 하자관리 교재입니다. 공동주택 입주 전후 사례를 중심으로 일반 건축물과 상업시설의 적용 차이도 익힙니다. 건축물의 구조와 공정을 이해한 뒤, 하자 발생·접수에서 조사·판정, 보수·검수, 비용 정산과 품질개선까지 연결합니다.

| --- | --- | --- |
| [01](./ROADMAP.md#01-건설업-기초) | 건설업 기초 | 누가 어떤 공사를 맡는지 파악하고, 단지·동·층·호·세대와 전유·공용의 위치를 설명합니다. |

## 학습 방법

1. 사진과 단면도에서 건축물의 위치와 부위를 찾아봅니다. 첫 등장 용어에서 한글·영문 명칭과 뜻을 확인합니다.
2. 정상과 하자의 비교 그림을 보고 관찰 사실과 원인 가설을 구분합니다. 법령, 계약, 설계도서나 조사가 추가로 필요한 지점을 표시합니다.
3. 가상 공동주택 사례를 따라 접수 → 조사·판정 → 보수 → 검수·종결 → 정산·품질개선 흐름을 읽습니다. 두 날짜나 상태가 같은 의미인지 자료를 대조해 확인합니다.
4. ERP 모형과 실제 기능 근거를 살펴봅니다. 담당자·권한·처리 조건·증빙을 확인하고, 보류·재작업·재발처럼 흐름이 달라지는 사례도 따라갑니다.
5. 확인 문제를 풀고 해설의 판단 근거를 비교합니다. 통합 실습에서는 타일 파손, 욕실 누수 등 여덟 사례를 접수부터 종결까지 추적합니다.
